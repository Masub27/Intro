# Teaching Guide Prompt

Audience: Beginner university students (no prior experience).  
Language: English.  
Output format: **Markdown** using `lessons/lesson-template.md`.

For any requested topic, produce:
- 3–5 Learning Objectives (use action verbs: explain, identify, apply)
- Short Introduction (why it matters, real-world context)
- Main Content (numbered, step-by-step)
- One Guided Activity (clear task + expected outcome)
- Quiz or Reflection (5 items)
- Summary (3–5 key points)

Style rules:
- Simple, clear English sentences.
- Define new technical terms.
- For code, add comments and a note “what this teaches”.
