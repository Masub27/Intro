# Machine Learning Basics

## 🎯 Learning Objectives

- Distinguish supervised, unsupervised, and reinforcement learning.
- Describe a simple ML workflow: data → features → model → train → evaluate.
- Try three short quizzes to check understanding.

## 📘 Introduction
Machine Learning is a branch of AI where systems learn patterns from data to make predictions or decisions. Instead of writing explicit rules, ML algorithms generalize from examples.

## 🧠 Core Concepts (brief)
1. Supervised learning — learns from labeled examples (e.g., classify emails as spam/not spam).  
2. Unsupervised learning — finds structure without labels (e.g., clustering customers).  
3. Reinforcement learning — learns by interacting with an environment and receiving rewards.  
4. Typical ML workflow:
   - Collect data
   - Prepare features
   - Choose a model
   - Train on training data
   - Evaluate on test data
   - Deploy and monitor

# Quantitative Research Methods

## 🎯 Learning Objectives
- Understand the key concepts of quantitative research.
- Identify appropriate research designs for quantitative studies.
- Apply basic data collection and analysis techniques.

---

## 📘 Introduction

Quantitative research is a systematic investigation that focuses on quantifying relationships, testing hypotheses, and generalizing findings to larger populations. It is widely used in fields such as social sciences, education, and healthcare to provide numerical insights into phenomena.

---

## 🧠 Main Content

### 1. Research Design

Research design outlines how a study will be conducted to answer specific questions. Common designs include:
- **Experimental**: Manipulates variables to establish cause-and-effect relationships.
- **Quasi-Experimental**: Similar to experimental but lacks random assignment.
- **Correlational**: Examines relationships between variables without manipulation.
- **Cross-Sectional**: Collects data at a single point in time.

---

### 2. Data Collection

Data collection involves gathering reliable and valid data using:
- **Surveys**: Questionnaires to collect responses from participants.
- **Structured Observations**: Systematic recording of behaviors or events.
- **Standardized Tests**: Pre-designed instruments to measure specific variables.
- **Existing Databases**: Using pre-collected data for analysis.

Proper sampling techniques, such as random or stratified sampling, ensure representativeness.

---

### 3. Analysis

Data analysis transforms raw data into meaningful results. Common techniques include:
- **Descriptive Statistics**: Summarizing data (e.g., mean, median, standard deviation).
- **Inferential Statistics**: Drawing conclusions about populations (e.g., t-tests, ANOVA).
- **Regression Analysis**: Exploring relationships between variables.
- **Factor Analysis**: Identifying underlying structures in data.

---

### 4. Ethical Considerations

Ethics in quantitative research ensure the integrity and credibility of the study. Key principles include:
- **Informed Consent**: Participants must be fully informed about the study.
- **Confidentiality**: Protecting participants' data and privacy.
- **Avoiding Bias**: Ensuring objectivity in data collection and analysis.
