# Machine Learning Basics

## 🎯 Learning Objectives
- Define what Machine Learning (ML) is.
- Distinguish supervised, unsupervised, and reinforcement learning.
- Describe a simple ML workflow: data → features → model → train → evaluate.
- Try three short quizzes to check understanding.

## 📘 Introduction
Machine Learning is a branch of AI where systems learn patterns from data to make predictions or decisions. Instead of writing explicit rules, ML algorithms generalize from examples.

## 🧠 Core Concepts (brief)
1. Supervised learning — learns from labeled examples (e.g., classify emails as spam/not spam).  
2. Unsupervised learning — finds structure without labels (e.g., clustering customers).  
3. Reinforcement learning — learns by interacting with an environment and receiving rewards.  
4. Typical ML workflow:
   - Collect data
   - Prepare features
   - Choose a model
   - Train on training data
   - Evaluate on test data
   - Deploy and monitor
